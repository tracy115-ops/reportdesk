# 办公工作台 / Office Workspace

办公工作台是本地优先的 Windows 桌面应用。办公助手、资料库、办公工具和团队汇报共用用户选定的来源。界面支持简体中文和英文，助手及团队汇报可分别设置输出语言。顶栏或 Ctrl K 可以搜索文件、材料内容、成果和功能。当前工作区布局及验证范围见 [界面与工作流重构](ui-workflow-review.md)。

办公助手的输入区已整合附件、格式、语言和发送操作；已有稿件时，消息区独立滚动，输入框保留在底部。布局参考和验证说明见 [输入与对话区域调整](assistant-ui-review.md)。

- **工作台**把不同位置的 Excel、Word 和目录保存为数据集。可预览数据集文件、带入表格汇总，或用这组资料新建 Agent 任务。手动附件每次最多选 12 份，数据集检索可覆盖当前数据集的可读资料。
- **周期汇报**从数据集选择本周、上周、本月或上月。运行时重新读取本地资料，按业务日期和已有列映射计算数字。可直接使用本地草稿，或把统计结果和摘录交给 Codex 撰写。报告中的引用可跳回原文。
- **办公指令**在助手输入框键入 `/` 或打开「命令」菜单，可以运行 `/周报 上周 导出 Word、PPTX 和 PDF`、`/月报`、`/Word` 和 `/PPT`。汇报提交前可核对数据集、周期和格式。在工作台可以用自然语言发起汇报，也可保存常用指令供其他数据集使用。
- **数据集活动**包含最近的报告和 Agent 任务。刷新详情列出新增、修改和移除的文件，并记录上次成功刷新。搜索可找出选定数据集中的段落、表格行和演示页，并将勾选的片段带入 Agent。
- **对话和知识库**支持从历史提问派生分支、回到之前的分支，以及在长对话中检索相关内容。助手选定数据集后，可切换到本地关键词检索或混合检索，并在发送前核对摘录。混合检索在「搜索与索引」中建库，使用模型广场配置的向量端点处理资料和问题。索引或端点不可用时，会提示回退到本地关键词检索。
- **技能与流程**把撰写、周期汇报、文件导出、多媒体和 MCP 调用组合为顺序步骤。技能可绑定触发词，步骤可引用指令和上一步输出，并按设置处理失败。
- **模型与多媒体**支持本机 Codex 和 Claude Code，以及 OpenAI 兼容、Anthropic 文本端点。配置相应兼容接口后可生成 PNG、MP3 和 MP4。Windows 使用 DPAPI 保护 API Key。
- **网页与项目验证**在「内置浏览器」打开开发服务器、包含 `index.html` 的静态目录，或从 HTML 成果进入浏览器。可切换视口，检查本地网页的标题、视口、图片、表单标签和横向溢出，也可打开 WebView2 开发者工具。小程序检查覆盖主包、分包和本地组件，运行时调试由本机微信开发者工具处理。两类检查结果均可保存为 XLSX，在「工作成果」中查看。
- **办公助手**默认进入通用对话，按 Enter 发送，Shift + Enter 换行。通过「Agent 设置」连接本机 Codex、Claude Code 或已配置的 API 文本模型。本机 Agent 可以从「工具」选定工作目录，查看原生工具的运行活动，并在完成或停止后核对本次新增和修改的文件。Claude Code 的回复会逐段显示，Codex 按 CLI 发出的消息和工具事件更新。需要交互审批时，可从工具菜单打开原生终端。对话、资料引用和稿件版本均保存在本机。
- **演示创作**从想法、助手稿件、团队汇报、表格汇总或逐页大纲进入。可从进展汇报、决策提案、复盘结构开始，在页面导航、画布和编辑面板之间完成工作；九种版式支持直接修改文字、备注和图表，也可粘贴数据或从 Excel 插入图表。拆页与局部 AI 修改后，从同一个项目导出 PPTX、独立 HTML 和 PDF。项目和含资料引用的近期版本保存在本机，支持备份。详细入口与流程见 [演示创作工作流](presentation-workflow.md)。
- **资料库**支持选取或拖放文件和目录。可以按来源、格式和读取状态筛选，按文件名或正文搜索 Word、Excel、PPT、PDF、CSV、TXT 和 Markdown，将整份材料或选中的原文带入助手。PDF 可以逐页渲染，PowerPoint 文件提供版式预览与检查。
- **表格汇总**支持选中多份 Excel 和 CSV，按相同表头对齐工作表，在本机做分组、筛选和计算。结果可跳回原表行。Excel 导出包含汇总、明细和统计口径，也能生成 Word、Excel 和带可编辑图表的 PPT。把汇总交给助手时，可以在发送前检查使用的数字与范围。Excel 公式使用文件里已保存的计算值。
- **资料操作**可以直接从文件发起会议纪要、Word 报告或演示稿。PPT 可直接进入检查，Excel 可直接进入数据整理或图表制作。在助手和办公工具内添加文件时会预选刚选中的资料。
- **办公工具**可预览 Word、Excel、PDF 和可编辑 PPT 后把本次结果存入成果。Excel 或 CSV 清理时显示保留和移除的行数。PDF 可调整合并顺序并提前核对页数。大纲转 PPT 支持主题和可编辑的 Excel 数据图。
- **检查 PPT**可定位缺失图片、超出画布的对象、过小字号、疑似文字溢出和空白页，按检查页与级别筛选后导出 Excel 清单。检查结果可跳到原页。字号依据文件里可读取的显式设置，文字溢出按文本框估算。
- **PPT 工作台**可按标题、正文、备注和文件名查找页面，收藏时保存可离线复用的副本，并为页面设置分类和标签。组稿支持重排、新建文字页和附上来源清单。导出文件保留可编辑的文字、表格和图表，不同比例的页面等比适配到首页画布。外部 PPT 的预览按常见对象近似渲染。
- **工作成果**支持按名称或时间排序，在文件操作中可选中同批交付的文件。可以预览、打开副本、重命名、另存或多选打包 ZIP。同名文件在同一个 ZIP 里会自动编号。
- **工作区备份**可从左下角「设置」导出 OFFICEBACKUP 文件，保存任务、稿件版本、报告、方案、生成文件、资料路径、办公工具草稿、表格汇总设置、PPT 收藏和组稿。恢复前会校验文件并显示内容概况。恢复后可以切回之前的工作区。
- **续用草稿和资料**时，办公工具会保留上次输入。资料来源移到新位置后，可在资料库重新连接并继续使用原有列映射与方案。备份保存原始资料的路径，换机后可连接对应文件或目录。
- **团队汇报**可保存常用团队、汇报类型和资料来源。目录中的表格可按工作表名称和表头复用列映射。Excel 根据业务日期筛选，文字材料可在开头标注「汇报周期：2026-11-16 至 2026-11-22」。周期待确认的资料可手动勾选。
- **汇报交付**可生成包含 Word、Excel 明细和核对记录、可编辑 PPT 的 ZIP。刷新来源时会标出变化，历史报告可以按生成时保存的数据重新打包。重新生成会把上一份草稿存入历史。

在 Windows x64 上，安装包使用系统 WebView2，文件处理可离线运行。执行 AI 任务时，选中的引擎会接收任务描述和相应资料节选。PDF 搜索适用于有文字层的文件。表格清理按值导出选定工作表。单份办公文件上限为 32 MiB，ZIP 和工作区备份的上限为 128 MiB。

## 连接第三方模型

从「设置 → Agent 设置 → 配置 API 模型」进入模型广场。添加供应商，选择服务支持的协议，填写 API 基址和 API Key。点「拉取模型」后勾选所需模型，也可以手填模型 ID 并按 Enter 添加。每个供应商都可以保存多个对话模型和一个默认模型。

从助手输入框旁的模型选择器切换模型。选定的模型也可用于文档和汇报。支持流式传输的服务会在生成时逐段显示对话回复。应用为 OpenAI 兼容服务追加 `/chat/completions`，为 Anthropic 兼容服务追加 `/messages`。

Claude Code 可使用用户设置或环境变量配置第三方网关。若在 PowerShell 中设置变量，请从同一窗口启动办公工作台。在 Codex 中配置兼容 Responses API 的服务商后，可在助手的「工具」中选择工作目录，让 Codex 读取其 CLI 配置。

开发需要 Node.js 22.12 或以上、Rust、Visual Studio C++ Build Tools 和 WebView2。在项目目录执行以下命令即可启动桌面开发环境。

```powershell
npm ci
npm run desktop
```

用 `npm run dev` 启动浏览器预览。桌面系统对话框、目录拖放、持久来源及 Codex 集成可在桌面版体验。

用 `npm run bundle` 生成 Windows x64 安装包。安装包在 `src-tauri/target/release/bundle/nsis`，同一构建的可执行文件在 `src-tauri/target/release`。
